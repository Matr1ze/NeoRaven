## Myau automatic Telly

The current `src/main/java/xyz/daikirai/module/player/MyauTelly.java` adapts
`src/main/java/poorcatgirl/module/modules/Telly.java` from **Myau-Poorcatgirl**,
by 蓝喵喵 / ltmy233, commit `ed9f237f055d27a4c6353b0db665d6b638194b26`:
https://github.com/ltmy233/Myau-Poorcatgirl

Its README describes the project as intended for learning and exchange, prohibits
resale, and requests its project link when recording videos. That revision does
not contain a standalone LICENSE file; NeoRaven's GPL-3.0 license must not be
interpreted as a license grant by this upstream author.

The earlier controller work also used **Myau-OpenTelly** by qinuan01, commit
`2714bc50202875b4e5096c7abfcc05244bba2c3c`, which includes a GPL-3.0 LICENSE:
https://github.com/qinuan01/Myau-OpenTelly

Upstream authors retain credit for their controller code. NeoRaven-specific work
connects it to this client's settings, input, motion, packet, and rendering APIs.
